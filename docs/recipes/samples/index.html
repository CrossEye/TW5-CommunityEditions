How to use a collection

  1. Open the empty edition and save a copy locally (use the “Save Changes” button in the wiki).
  2. Download a JSON collection from the tables above.
  3. Open your saved empty edition in a browser, then drag the JSON file onto the wiki window. The contents appear immediately; remember to save again.

More collections are planned (smaller demos, metric-units variants, additional locales). This is a temporary host; URLs will move when the editions site ships.
